# SVS Cricket Academy website

- index.html        : public website (Supabase admission form, photos from admin)
- admin.html        : admin dashboard (enquiries + Photos tab for academy/coach photos)
- supabase.sql      : tables, RLS, admin allow-list  (run 1st)
- supabase-media.sql: photo storage bucket + site_images table (run 2nd)
- images/           : optional local fallback photos

Deploy: upload this folder to Netlify. Admin page: /admin.html
